# Moonpetal

A cute anime inspired survivor game in the browser. Guide Mina through three moonlit realms, collect moon crystals, choose charms, and defeat each realm's guardian.

## Run it

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Controls

- **WASD** to move. Arrow keys work too.
- **Space** toggles auto attack. It starts on, and targets the nearest spirit.
- **Esc** pauses or resumes.
- **1, 2, or 3** chooses an upgrade when Mina levels up.
- **Enter** starts a run, enters the next realm, or starts again after a run ends.

Defeat the guardian in each stage to open the path to the next realm.
